SoloCrawl 1.1.0 improves fetching reliability, package version resolution and dependency security.

### Changes

- Validate configuration values and pass explicit configuration to built-in providers.
- Fix sticky proxy recovery and report exhausted proxy pools without falling back to direct access.
- Check redirect destinations against URL/DNS safety rules and robots.txt before requesting them.
- Guard Chromium navigation, frames and subrequests; fix the aborted-navigation redirect race.
- Improve version range parsing, SemVer prerelease handling and numeric four-part releases.
- Handle PyPI yanked releases, Swift tag pagination and Go module case encoding correctly.
- Upgrade to FastMCP 4 and update dependencies, including patched transitive dependency floors.
- Add a Python verification runner, JSON reports, MCP protocol tests and local Chromium tests.
- Update CI and project documentation.

### Compatibility notes

- The unsupported anonymous Reddit search provider has been removed. Existing configurations
  enabling `reddit` no longer select it. arXiv and optional SearXNG remain available.
- Invalid configuration values now fail early with an explanatory error.
- Main-page browser redirects work; redirected iframe, script and XHR requests are aborted to
  preserve URL safety, credentials and browser origin isolation.
- Python 3.14+ is required. Install Chromium separately when using the browser extra.
- The five public MCP tool names remain unchanged.

### Verification

The maintenance changes passed offline, MCP, Chromium, clean wheel installation and dependency
audit checks. All ten package registries and the retained public search providers passed live
checks; arXiv passed on retry. SearXNG was not tested because no instance was configured.
Release artifacts are built and checked separately with version 1.1.0.
